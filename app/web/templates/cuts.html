Room cuts

A room is a venue of a game. Set a cut here for one room of one game and it replaces the game's default there. Most specific wins: an Agent's own row for the room, then the Agent's account-wide cut above, then the room's default, then the game's default. For SOP %, the Agent's row for the room wins first: Agents set it themselves for their own Sub Agents in the Agent Panel. Blank = fall through to the next level.
