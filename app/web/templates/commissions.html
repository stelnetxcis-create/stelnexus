How commission is calculated

Each game's pool is split Master Agent → Agent → Sub Agent. The Agent side keeps the Volume % of the pool and the Master Agent gets the rest; the Sub Agent's SOP % comes out of the Agent's cut, not on top of it. A player placed straight under an Agent has no Sub Agent, so the Agent keeps the whole Agent cut.
